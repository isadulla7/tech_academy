# 🚀 Tech Academy v1

> **Android, Kotlin, Java va Fintech Masterclass Ta'lim Platformasi**  
> 0 dan Senior darajagacha bo'lgan chuqur nazariya, xotira sxemalari, mental modellar va bank production amaliyoti.

---

## 📌 Loyiha haqida

**Tech Academy v1** — bu to'liq offline ishlovchi, eng zamonaviy Dark Mode interfeysga ega interaktiv ta'lim tizimi. Loyiha Android, Kotlin, Java backend, multi-threading, xotira arxitekturasi va fintech/banking integratsiyalarini o'rganish uchun mo'ljallangan.

Har bir dars quyidagi qat'iy tizim asosida yoritilgan:
1. **💡 Amaliyotdagi holat** — Real bank va ishlab chiqarishdagi keyslar.
2. **1. Muammo nima?** — Mexanizm paydo bo'lishidan oldingi tizim/apparat muammosi.
3. **2. Eng sodda mental model** — Kundalik hayotiy analogiya (ish stoli, omborxona, kuryer va h.k.).
4. **3. Xotirada va baytkodda nima sodir bo'ladi?** — ASCII arxitektura sxemalari (Stack vs Heap, CPU registers, Bytecode).
5. **4. Amaliy kod** — Aniq, toza Kotlin/Java/SQL kod namunalari va tahlili.
6. **5. Boshqalarga buni qanday tushuntirasiz?** — Senior darajasidagi so'zma-so'z formula.
7. **🔬 Chuqurroq (Deep Dive)** — Kompilyator sirlari, runtime mexanizmlari, AOT/JIT, Escape Analysis.

## 🛠 Texnologiyalar

- **Frontend:** Pure HTML5, CSS3 (Modern Developer Dark Theme), Vanilla JavaScript (ES6+).
- **Arxitektura:** Server talab qilmaydi, 100% Client-side va Offline-first (PWA manifest mavjud).
- **Xotira boshqaruvi:** O'rganish progressi, tushunilmagan savollar va qaydlar brauzerning `localStorage` xotirasida saqlanadi.

## 🚀 Qanday ishga tushiriladi?

Hech qanday o'rnatish (`npm install` yoki server) talab qilinmaydi:
1. Repozitoriyani yuklab oling yoki klon qiling:
   ```bash
   git clone <repo-url>
   ```
2. Loyiha papkasidagi `index.html` faylini istalgan brauzerda (Chrome, Edge, Safari, Firefox) oching.
3. Klaviaturadagi tugmalar bilan qulay boshqaring:
   - `→` (O'ng strelka): Keyingi dars
   - `←` (Chap strelka): Oldingi dars
   - `Escape`: Oynalarni yopish
